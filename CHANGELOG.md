## [0.1.5] - 2026-09-14

### Changed
- Диагностика записи в поток в C++ реализации общего модуля приведена к виду C-части: errno обнуляется перед операцией и фиксируется в точке сбоя, текст единый — <фаза>: <описание ошибки> (errno N), фазы (заголовок / пиксель / сброс) сохранены. Раньше при одном и том же сбое C и C++ печатали разные сообщения
- Разбор чисел заголовка и пиксельных данных унифицирован между C и C++: обе реализации читают полный токен и одинаково различают отрицательное значение, дробное, знак +, нечисловое, переполнение (> INT32_MAX) и конец файла; C++ переведён с operator>> на токенный разбор с from_chars, формулировки сообщений совпадают
- Ошибки чтения в C++ ppm_io больше не выдаются за конец файла: сбой потока определяется отдельно, в сообщение добавлен (errno N), как в C
- Задача 2, C++: код системной ошибки фиксируется в точке сбоя (PassportError::system_error), а не читается из глобального errno при печати 
- Задача 2, C: read_passport принимает FILE* и возвращает результат через PassportResult (добавлены bad_value и system_errno) вместо печати внутри функции; текст формирует passport_error_message, формулировки выровнены с C++ и эталоном. Архитектура C++ при этом не копировалась — остаётся одна структура результата
- Эталоны четвёртой задачи: «вакуумные» эталоны (checker ×2, radial threshold) заменены на probe-набор 2×2 и 3×3 с пикселями, попадающими на границы — прежние такие случаи не ловили; grayscale-эталоны gradient и radial оставлены
- Юнит-тесты фильтра переведены на проверку отдельных пикселей, интеграционные сценарии из них убраны (в README из описания тестов фильтра убрано «и integration»)
- Имена .ppm в README приведены к единой схеме <описание>_<WxH>[_<фильтр>].ppm: у задачи 4 убран префикс ref_, разделитель размеров приведён к x, имена случайных входов выровнены

### Added
- Добавлены флаги для сборки и линковки Release стенда
- Тесты обрыва записи в C++ реализации общего модуля через управляемый streambuf (ControllableBuf) — проверяются и текст сообщения, и зафиксированный errno
- Тест сбоя чтения в C++ ppm_io через FailingInputBuf (errno + badbit) — проверяет, что поднимается именно IO-ошибка, а не конец файла
- Тесты разбора чисел заголовка и пикселей в C и C++ на все виды некорректного ввода (отрицательное, дробное, нечисловое, переполнение, EOF) с проверкой текста диагностики
- Тесты read_passport в C++ и C: валидный ввод, отсутствие ввода, пустое имя, некорректное и отрицательное количество, реальный путь IO
- В README для задачи 2 — команды сборки тестов (C: +read_passport.c +strerror.c; C++: +read_passport.cpp), описание состава тестов и заметка про приём FILE*
- В README для задачи 4 — таблица эталонов, блок сборки девяти программ, полный probe-пример приёмки (сборка генераторов → генерация → прогон → сравнение) и команды генерации эталонов; счётчик программ обновлён до 18

## [0.1.3] - 2026-08-31

### Changed

- На основании изменения внутренней структуры проекта были изменены команды сборки, а также тесты. Теперь luma - часть common, и тесты на нее расположены в каталоге общего модуля
- При обрыве потока записи C реализация первой и четвертой задач теперь вместо кода 0 имеет код 74 и диагностическое сообщение 
- Изменена сборка общего модуля в C части, так как теперь в нее входит также файл strerror.h

### Added

- Добавлен процесс сборки генераторов эталонных изображений для первой задачи
- В диагностику первой задачи добавлен диапазон чисел для seed, которые являются валидными
- Добавлены команды для сборки и запуска тестов для общего модуля
- Добавлены тесты общего модуля на обрыв при записи в его C и C++ реализациях 

### Fixed

- Реализована обработка ошибки выделения памяти в С++ общем модуле, за счет чего теперь stats и filter работают корректно в случаях ввода больших размерностей изображения. В прошлом на таких вводах программа падала с системным кодом
- Исправлены команды сборки тестов для фильтра изображений

## [0.1.2] - 2026-08-25

- Обновлены команды сборки/запуска в README в соответствии с новой структурой проекта

### Fixed

## [0.1.1] - 2026-08-08

### Fixed

- Исправлена сборка проекта на Linux — ранее она завершалась ошибкой из-за использования `strerror_s`, которой нет за пределами Windows.
- Исправлена сборка C++-версии — отсутствовало явное приведение типа результата `malloc`, из-за чего компиляция могла падать

## [0.1.0] - 2026-08-07

### Added

- Генератор PPM-изображений (`P3`) с тремя паттернами: gradient, checker, radial
- Поддержка воспроизводимой случайной генерации через `--seed`
- Команда для вывода паспорта изображения (размеры и т.д.) с корректным русским склонением слова «пиксель» в выводе
- Команда для вычисления статистики изображения из stdin: размеры, средний цвет, минимальная/максимальная яркость, гистограмма яркости (8 корзин)
- Поддержка PPM-файлов с `#`-комментариями в заголовке при чтении
- Фильтр изображений: `--threshold` (бинаризация по яркости) и `--grayscale` (перевод в оттенки серого)
- Все программы (`gen`, `filter`, `stats`, паспорт) можно объединять в конвейер, например `gen | filter | stats`
- Флаги `--help` и `--version` во всех четырёх программах
- Разные коды завершения для разных типов ошибок (некорректные аргументы, некорректные данные, отсутствие входных данных, ошибки ввода-вывода) — удобно для обработки в скриптах
